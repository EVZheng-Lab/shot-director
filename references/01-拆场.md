# 01 拆场：剧本 → 场

> 来源：EV 11-06 定义；15 期 Q59（行业与剧作理论）；ad-asset-bible 第 1–2 步（场次切分与地点去重）。

## 一、定义（EV 定，不改）

**场 = 发生在同一个场景中、由同一批演员完成的一段或连续几段事件。**

只看两件事：**场景变没变、演员换没换批**。情绪变化不切场。

| 情况 | 切不切 | 理由 |
|---|---|---|
| 情侣在咖啡厅聊天，聊着聊着吵起来 | 不切 | 同一场景、同一批人；情绪转折是场内节拍，交给镜头组 |
| 情侣还在，父母过来坐旁边窥视、议论他们 | **切** | 新来的人带着自己的目的进场，演员换批 |
| 服务员上菜、路人走过、司机开车 | 不切 | 功能性进出，不带自己的目的 |
| 有人带着目的下场，留下的人开始一段独立的戏 | **切** | 演员批次变了 |
| 同一批人从卧室走到走廊（同一处地产内连续走动） | 不切 | 地点资产可能换（看资产盘点），场不切 |
| 时间跳跃（第二天、几小时后、闪回） | **切** | 不是“连续”的事件 |
| 电话两头对切 | 一场 | 地点写“A / B 对切”，两份地点资产都挂 |

**判“换没换批”的自检**：新来的人删掉，后面的戏还成立吗？成立 → 他只是功能性进出，不切。

**本来就在场的人转为主动**（酒吧里一直坐着的众人起身阻拦、一直在客厅的继母开口帮腔）：演员没换，**不算换批**，不切场；这是场内节拍，交给镜头组。

## 二、场号：继承副导演，不另起一套

1. **场号沿用资产盘点（ad-asset-bible）的场次号**（如 `11-1`，重号消歧的 `102-1*` 照用）。资产的 `scenes` 字段就是按它登记的，换一套号就对不上账。
2. 副导演切开的场次**不合并**（他按地点 + 时间切，我们的定义只会切得更细，不会更粗）。
3. 一个场次里演员换批了 → 拆成几场，场号加大写字母后缀：`1-1A`、`1-1B`；`bibleScene` 写原场次号 `1-1`。
4. 剧本没有场次号：资产盘点里副导演已经编过（`S01`…），照用。
5. **同一场被集与集的边界切开**（上一集末场和下一集首场其实是同一场）：保留两个场号，不合并——集是播出和剪辑的单位。在后一场的 `splitReason` 里注明“和上一集末场 ×-× 是同一场，被集边界切开”，并填 `"continues": "×-×"`——脚本会把两场当成一场查交界和轴线；状态也照同一场处理（EV 11-07）。
6. **交叉剪辑回切**（楼上 → 楼下 → 楼上，A/B/C 三场）：回到原地点的那一场同样填 `continues` 指向它接着的那一场（例：2-1C 的 `continues` 写 2-1A），脚本会查两者的交界和左右站位。

## 三、每场要写的字段

| 字段 | 写法 |
|---|---|
| `name` | 一句话场名：地点 · 时段：发生了什么 |
| `loc` | 主地点资产 tag（可以是变体，如夜景 `@loc_xxx_ye`） |
| `cast` | 主要角色的**服装资产** tag（`@char_<人>_<服装>`，不是底档）；有状态变体（溅血、湿透）就用变体 tag |
| `extras` | 不建档的群演，写清“有台词 / 不说话 / 画外音”——它决定派不派 H3 |
| `summary` | 现在时，谁做了什么；不写形容词评价 |
| `splitReason` | 为什么在这里切（或为什么不切）——导演审本子主要看这一条 |
| `anchor.from / to` | 起止原句，**逐字**摘剧本（脚本会拿它去剧本里定位、核台词） |
| `unsure` | 拿不准的判断如实列出：场记和正文矛盾、地点归属存疑、错别字等 |

## 四、易错点

- **场记头和正文打架**：以正文 △ 动作行为准，场记的写法记进 `unsure`（例：场记写“公交站点夜外”，动作全在行驶的车厢里）。
- **不要因为情绪转折切场**（聊天 → 吵架是一场）。网上不少 AI 分镜项目把“情绪高潮”当场边界，那切的是生成片段，不是场。
- **不要修剧本**：发现剧本逻辑错误、错别字，记进 `unsure` 反馈给导演，分镜照原文。

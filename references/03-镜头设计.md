# 03 镜头设计：一个镜头组里切哪几个镜头

> 来源：AIMV storyboard-designer（导演视角声明、4 条 AIGC 硬约束、cinematography/ 资料）；官方 higgsfield-shotlist-director（Off-screen 行、动作接剪、单调检查、FOV）；官方 Acting（反应比动作值钱）。

## 一、导演视角：不是翻译剧本

- 剧本写的构图、景别只作参考，镜头怎么切由分镜导演决定。先问三件事：**观众需要知道什么？什么镜头能让他看懂？角色首次出场、场景首次出现该怎么交代？**
- **新场景先建立空间**：场景第一次出现，第一个镜头组的首镜交代环境（可以是空镜，也可以人和环境同框）。纯空镜堆砌不算——空镜要有交代空间的作用。
- **反应比动作值钱**：重要事件（威胁、消息、侮辱）之后，最值钱的镜头是“看到它的人”的脸。对白戏别只拍说话的人。
- **借剪辑出情绪（库里肖夫效应）**：表情不够用时，“无表情的脸 → 插入他看到的东西 → 回到同一张脸”，观众会自己读出情绪。AI 表情控制差的时候尤其好用。
- **观众先知道（希区柯克炸弹理论）**：要悬念不要惊吓时，先给观众看危险（桌下的炸弹、下了药的杯子），再拍毫不知情的角色，中间再插一次危险。
- **重要的东西给大（希区柯克法则）**：道具在画面里多大，取决于它此刻在剧情里多重要；证据、伏笔给插入大特写，无关道具别给特写。
- **视线 → 落点**：人物在看什么，下一个镜头给出看到的东西（“问题 → 答案”结构）。

## 二、每个镜头写什么

每个 Shot 一行，依次写：**景别 + 视角/运镜 → 画面里谁在哪、在做什么 → 台词（如有）**。

- 景别：远景 / 全景 / 中景 / 近景 / 特写 / 大特写；双人、过肩、主观视角照写。
- 运镜：固定、推、拉、摇、跟、手持。一个镜头一种运镜；一个组里运镜不超过 2 种（02 复杂度预算）。
- **人名运镜**（希区柯克变焦、迈克尔·贝环绕……）见 `09-人名运镜.md`：剧情里有对应的时刻才用，**一场最多一个**，写成“中文名（英文名）：画面描述”。
- 提示词一律中文（EV 11-07），用景别词即可，不写毫米焦段。
- **反打用资产盘点的机位变体**：副导演给场景登记了反打变体（如 `@loc_xxx_fanda`），反打镜头就挂那个变体，不在提示词里描述反打那侧长什么样。

## 三、跨镜头组的连贯

- **每个镜头组的提示词都是独立上下文**：模型不记得上一组。禁止“和上一组同样位置”“比之前大一些”“与组 1 同款”这类相对说法，一律写绝对状态。
- **刚离场的人写一行“画外”**：上一组在、这一组不在的角色，写“已从画面左侧离开，手里还拿着 X”，保证下一次入画方向对。连续缺席两组后不再写。
- **动作接剪**：相邻两组要接得上，就让上一组结束在某个动作上、下一组从同一个动作开始（例：上一组举手要拉人，下一组从拉人那一下开始）。
- **状态带到下一组**：受伤、湿透、外套脱了等，场内已经发生的状态变化要写进后面每一组（有状态变体资产就挂变体）。

## 四、镜头组之间的衔接（EV 11-07，脚本会查）

同一场里，**上一组的最后一个镜头**和**下一组的第一个镜头**是直接剪在一起的，必须满足三条：

1. **景别至少隔一级**：景别顺序 远景 → 全景 → 中景 → 近景 → 特写。远可以接中，远不能接全；中可以接特，中不能接近。
2. **拍摄角度变化大于 30°**：用水平角度记（正面 0°，斜侧 30°，侧面 90°，斜背 150°，背面 180°）。正面不能接斜侧，可以接侧面。
3. **不越轴**：同一场里两个人的左右关系保持不变。上一组男左女右，下一组也必须男左女右。确实要换边（摄影机运动带过轴线、中间插了一个正对轴线的中性镜头）时，在下一组写 `axisChange` 说明理由。

- **景别、角度两条只管同一个主拍对象**：交界两边拍的是同一个人（或同一处空镜），才要求景别隔一级、角度变化 >30°。换了主拍对象（正反打从 A 切到 B、从人切到手部或道具特写）不受这两条限制——那本来就是正常剪法。**越轴那条始终要查。**
- **角度相对本镜的主拍对象算**：0° = 正对他的脸，90° = 正侧面，180° = 拍他后背。
- **插入特写**（手部、道具、屏幕）：`lr` 写画面里看得到的人，看不到人就写 `[]`；`subject` 写物件名。

每个镜头组都要填 `edge`：首镜和尾镜各写主拍对象 `subject`、景别、角度、画面里从左到右是谁（空镜写空数组）。

```json
"edge": {
  "first": { "subject": "童嘉许", "size": "中景", "angle": 0,  "lr": ["梁泰声", "童嘉许"] },
  "last":  { "subject": "童嘉许", "size": "近景", "angle": 90, "lr": ["童嘉许"] }
}
```

写完一场后竖着读一遍每个交界处；脚本会按这三条报错。组内相邻镜头也尽量照这三条切（脚本不查组内）。

## 四之二、反应镜头（EV 11-08，脚本会查）

demo 的对白组几乎都是“谁说话拍谁”，一正一反来回切，听的人一直没脸——这是要改的。

**什么时候必须给**：对白组里出现了**要命的那句话**（威胁、揭秘、侮辱、表白、拒绝、坏消息、下命令），下一个镜头（或这句话说到一半）要切到**听到这句话的人**的脸。交代信息的平常对话可以不给。

**三种拍法**（按安全程度排）
1. **过肩，听者朝镜头**：说话人背对镜头在前景、嘴看不见，听者正脸在后面——最不容易把台词嘴型安错人，首选。
2. **话说完的停顿里**：台词落地后，切到听者近景，他还没开口，脸上已经有反应（07 第二节第 6 条“反应先于台词结束”）。
3. **台词垫在听者脸上**（J/L 剪）：说话人的声音在画外继续，画面是听者。风险是模型让听者跟着张嘴，必须写明：`甲的声音在画外继续，乙嘴唇紧闭，没有说话`。长台词可以用这种办法拆成“说话人镜头 + 听者镜头”两段。

**标准句式**
- 过肩：`过肩近景，从甲身后拍乙。甲在画面左侧前景，背对镜头，只露出肩头和后脑，嘴看不见；乙在画面右，正脸朝镜头。甲的声音继续：{……}乙嘴唇紧闭，没有说话，……`
- 垫在听者脸上：`甲的声音在画外继续：{……}乙嘴唇紧闭，没有说话，……`

**几种边界情况（11-08 第一轮试跑后定）**
- **反应落在下一组首镜**也算：本组写 `noReaction: "反应在下一组首镜（××）"`。
- **内心独白**别人听不见，不需要反应镜头；但独白本身照样要导（语气、停顿、边想边做），按 07 二之二写。
- **反应镜头别放在组尾**：组尾放听者近景，常和下一组首镜是同一个人、景别只差一级，过不了衔接检查。优先插在组中间。
- **时长顶到上限**（SD2.0 15 秒）：断句、停顿加反应会把长台词组撑满。宁可拆成两组，不要为了塞进 15 秒丢掉反应或关键动作。
- **群演说话的 H3 组**脚本不查（没挂两个角色），但要命的话照样要给反应，自己检查。

**反应怎么演**：按 07 写——反应要具体（眼神停住、喉结动一下、手里的东西攥紧、往后靠），不写“很震惊”；强势的人反应小，弱势的人反应大。

**写进 JSON**：每个反应镜头在 `reactions[]` 里登记一条 `{ "shot": "Shot02", "who": "沈云卿", "on": "沈云乔说‘你不配’" }`。

**脚本查什么**：参考生视频组里有台词、而且挂了两个及以上角色 → 必须有 `reactions[]`，或者写 `noReaction` 说明为什么这组不给（例如“只是问路的平常对话”）。登记的 Shot 要在提示词里找得到、里面要写到这个人；那个 Shot 里如果有别人的台词，要写明“画外”。

## 四之三、平面图与站位锚（EV 11-09，脚本会查）

### 平面图：每一场都画

每一场在 `blocking` 里至少画一张俯视平面图，相当于现场的机位图：
- `marks[]`：场地里的固定物（正厅、踏道、门、栏杆、楼梯、摊位），x、y、w、h 都按 0–1 写，上 = 北。
- `top[]`：每个人站在哪、朝哪（`face`）。同一类群演可以重名（几个“仆役”）。这一段里有人走位、被推、倒地，写 `to: [x, y]`（和可选的 `toFace`），图上画虚线箭头。
- `cams[]`：**这一场每一个 Shot 都要有一台机位**，`at` 写“组号 ShotNN”，加位置、朝向 `aim`，可选 `fov`（特写 30 左右，常规 50，全景 70）。拍的是走位之后的，写 `after: true`。
- `ratio`：图的宽高比，默认 1.3；街道、挑台这种狭长场地写 2。

一张图一个阵型。阵型大变（宣旨跪拜 → 刺杀后众人起身逃散）就另起一张（B、C…），别在一张图上堆十几台机位。被集边界切开的同一场（`continues`），可以把机位画在上一段的图上。

**脚本对账**：把平面图投影到每台机位，算出“从这台机位看，谁在左、谁在右”，和草图里人的左右顺序比，对不上就报错。组和组之间人物左右跳边、站位漂移，最常见的原因就是每组凭感觉写左右——平面图就是左右关系的唯一依据。改的时候先想清楚意图：是机位放错了就挪机位，是草图画反了就改草图，同时改提示词里的左右和 `edge.lr`。

### 站位锚：多人阵型跨组时再加一步

同一个阵型（谁跪在哪排、谁站在谁身后、几排人的前后）**跨两个以上镜头组**出现时，光有平面图还不够——每组分开生成，模型看不到平面图，站位一样会漂。这时把那张平面图标成 `anchor: true`，做成站位锚：

**什么时候要锚**：一场里有一个“摆好就不怎么动”的多人阵型（跪拜、列队、围坐、对峙站位），而且至少两个镜头组都拍到它（哪怕只拍到一部分）。两个人一前一后、一句话说得清的不算。

**怎么锚**
1. 在这张平面图上补一段给 Blender MCP 的静态站位提示词 `prompt`（08 模板 B，每台机位出一张站位图）。
2. 这些镜头组都挂上**同一套站位图**里自己那台机位的那张：`refs` 加一条，tag 写 `站位图·<站位名>·<机位>`；提示词里写 `@imageN 是 Shot01 机位的灰模站位图：只参考人物在院子里的位置、前后排、朝向和机位构图，不参考灰色外观和小人的样子；人怎么动按文字。`
3. 站位锚**不改模型**：H3、SD2.0 的组照样挂站位图（它只是一张参考图），不因为它升到 SD2.5。会动的复杂关系仍按 08 判 `full`。
4. 阵型变了（有人起身走开、众人逃散），之后的镜头不再按这个锚，画到下一张平面图上；需要的话另开一个锚。

## 五、整场写完后的两项检查

1. **单调检查**：把一场所有镜头的“景别 + 运镜”竖着读一遍，不能连续 3 个镜头景别和运镜都一样（比如全是“中景、固定”）。换的是镜头的作用和大小，不只是时长。
2. **反应镜头检查**：每个重要事件之后有没有给反应（见四之二）。

## 六、AIGC 约束（AIMV 复盘得来，第 2 条已按模型手册改写）

1. **跨镜头组独立上下文**（见第三节）。
2. **细微生理反应按各模型手册写**（EV 11-07：AIMV“一律不写”是旧模型的结论，作废）：SD2.0 可以用身体细节外化情绪（肩膀微微颤抖、眼眶泛红）；SD2.5 用描述性语句、不用强烈情绪词；H3 的微表情只放近景/特写。细则见 05、07。
3. **画面里有文字就标警告**（EV 11-07：现在的模型渲染文字基本可以）：手机消息、邮件标题、招牌、信件照常写进提示词，但该组填 `textRisk`（如“手机屏幕上的 QQ 消息：‘……’”），页面会标“⚠ 有文字，有渲染失败风险”。精细图案、徽记、图纸仍尽量改成实体道具或动作传达。
4. **打字发出的消息、屏幕上的字不算台词**，不进 `lines`；写进提示词并填 `textRisk`（见第 3 条）。
5. **组内中途才出现的状态**（流血、流泪、衣服撕破）：组开头就有 → 挂状态变体资产；组内才发生 → 挂原状态的资产，变化用文字写，下一组起再挂变体。
6. **回忆、梦境、闪回**：用场级 `stylePrefix` 覆盖全局前缀（例如加“褪色、低饱和、轻微暗角、柔焦”），整场一致；光源和日夜变了同样用场级前缀覆盖，不只限日景 / 夜景。
7. **可能过不了平台审核的动作**（击打要害、血腥特写、揪头发等）：照剧本写，但在该场 `unsure` 里标出，建议导演考虑拆镜、遮挡或用声音代替画面。
8. **关键画面用“遮住 → 揭开”**：重要道具或完成时刻先遮后揭，可配一次升格；一个镜头组最多一处升格。

## 七、草图（EV 11-08）

人不爱看字。每个镜头组给一条草图，**每个 Shot 一格**，用图标小人拼（不是真人、不调大模型），导演扫一眼就知道这组的调度：谁在画面哪边、什么姿势、脸朝哪、景别多大、镜头怎么动。

- 小人从**姿势库**取：`templates/poses.js`；预览页 `Output/姿势库.html`（`node scripts/poses-gallery.mjs` 重新生成）。库里没有合适的姿势就选最接近的，在 `note` 里补一句；常缺的姿势记下来，让维护者往库里加。
- 头上的**橙点 = 脸朝向**：侧面姿势 `face` 写 `right` / `left`（脸朝画面右 / 左）；正面姿势写 `front`（脸朝镜头）、`back`（背对镜头，过肩镜头前景的那个人）、`fl` / `fr`（四分之三侧，脸偏画面左 / 右）。
- `cam` = 机位高度：`俯拍` / `仰拍` / `顶拍` / `主观`，平视不写；草图左下角会标出来。
- 全景、中景、远景里有 2 人以上时，小人会自动缩小，免得挤成一团；还挤就把 `x` 拉开。群演可以用“人群”“仆役”这类名字区分，不要都叫一个名字（同名会和 edge 对账打架）。
- 小人只交代谁在哪、什么姿势、景别多大。脸上的戏（抿唇、眯眼）和中箭、刺入这类过程画不出来，写在 `note` 里。
- `x` = 小人在画面里的左右位置（0 最左，1 最右）；`s` = 相对大小（过肩前景的人写 1.3 左右，远处的人写 0.7 左右，默认 1）。
- 景别决定画框里看到多少：远景、全景看全身；中景到腰；近景到胸；特写只有头。
- 用了人名运镜的那一格加 `"named": "希区柯克变焦"`、`"namedWhy": "一句话"`（09）。
- `move` 写这个镜头的运镜（固定、推、拉、摇、跟、手持、环绕、人名运镜……），画框上会叠对应的箭头图标。
- `props` 只放关键道具（剑、信、手机），`note` 一句话说这个镜头在干什么。
- 空镜：`figs` 留空，`note` 写拍什么。

```json
"shots": [
  { "n": "Shot01", "size": "近景", "move": "固定", "figs": [{ "who": "沈云卿", "pose": "stand_f", "face": "fl", "x": 0.5 }], "note": "沈云卿看着剑，问为什么" },
  { "n": "Shot02", "size": "近景", "move": "固定", "figs": [{ "who": "沈云乔", "pose": "stand_f", "face": "back", "x": 0.2, "s": 1.35 }, { "who": "沈云卿", "pose": "stand_f", "face": "fl", "x": 0.7 }], "note": "过肩：沈云乔背对镜头骂，给沈云卿的反应" }
]
```

**脚本查**：格数 = 提示词里的 Shot 数；姿势名在库里；`x` 在 0–1；首格、尾格从左到右的人要和 `edge.first.lr` / `edge.last.lr` 一致。

# 05 视频提示词 · 参考生视频（SD2.0 / SD2.5 / H3 / Wan3.0）

> 管 `groups[].prompt` 里 `craft = r2v` 的四个模型怎么写。首帧档（Omni）不在本文件。
> 骨架 = 官方 Shotlist Director（前缀 → 角色 → 场景 → 逐镜头）；表演改写看 07；LAYOUT 怎么搭看 08。
> 每条规则的出处见第八节，资料之间打架的地方列在第八节末尾；**EV 11-07 已裁定的按裁定写**，没裁定的暂按"默认"一栏写。
> **语言（EV 11-07 已裁定）：提示词一律中文**（Skill 给中国大陆用户，方便读改；Seedance 2.0/2.5 火山方舟官方指南、H3 手册是中文，Wan3.0 官方中英都行）。

## 一、四个模型共用的规则

### 1.1 结构（从上到下，顺序固定）

```
[meta.stylePrefix 原样]
[挂载声明：@image/@video/@audio 各是什么]
[声音：本组开口角色的 voice 四要素]        ← 没人开口就整段不写
[一句话概述]                              ← SD2.5、H3、Wan 必写；SD2.0 可省
Shot01：……
Shot02：……
[音效 / 音乐 / 约束收尾]
```

### 1.2 全局前缀
- `meta.stylePrefix` **逐字**贴在最前面，一个字不改（Shotlist：改一次全局生效）。
- 不在前缀后面再补风格词；要补就改 `meta.stylePrefix`，全片一起变。
- 前缀里写死了"夜景"这类光线时，日景那一场在 `scenes[].stylePrefix` 写一条覆盖前缀，这一场的组都以它开头（build.mjs 已支持）。
- 前缀 + 声音四要素原样贴之后超过 500 字也照贴，不为凑字数删前缀或声音（EV 11-07）。

### 1.3 挂载声明句式
- 写法：`@image1 是童嘉许，@image2 是梁泰声，@image3 是夜里的公交车厢。`
- **只写身份，不写长相**：角色只写名字；场景写地点名（"夜里的公交车厢"），不写装修、材质、布局。
- 顺序 = `groups[].refs` 的顺序 = 上传顺序。排 refs 时：**角色按本组首次出场顺序 → 道具 → 场景 → @video → @audio**（2.5 官方：按出场顺序排，防角色错位；2.0 官方：越要精准的越靠前）。
- 绑一次就够：后文直接用名字（"童嘉许"），不在每个 Shot 里重复 `@imageN`。
- `@imageN / @videoN / @audioN` 编号**原样保留**，和 refs 表一一对应、连续不跳号（build.mjs 会查）。**一律写 `@image1 / @video1 / @audio1`，不写"图片1""@图片1""图1"**（EV 11-07：各平台都认得）。
- `@video` 必须写清"参考什么、不参考什么"（EV 11-07：LAYOUT 视频默认只取位置、路线、机位和时序，不照搬灰模外观和人的动作）：
  `@video1 是灰模预演：只参考其中[对象]的位置、路线、先后顺序和摄影机运动；不参考它的灰色外观、方块形状和辅助线，也不参考小人的动作。`
  叠了参考图时补一句对应关系：`@video1 里的长方体是公交车，三个黑色方块是轿车。`
- `@audio`（v1 不做参考音频锁声，出现时才写）：`@audio1 是童嘉许的声音参考，她的台词用 @audio1 的音色。`
- 参考生视频里**不写"@image1 作为首帧"**：首帧与参考是两种互斥的任务（Seedance/H3/Wan 官方），要首帧就改派首帧档。2.5 想钉死某一帧，用"关键帧参考"（`以 @image1 至 @image3 的顺序作为关键帧`）。

### 1.4 不写外观（EV 拍板）
| 不写 | 照写 |
|---|---|
| 挂了图的角色：脸、发型、体型、年龄、服装、配饰、疤痕 | 名字 |
| 挂了图的场景：房间类型、装修、家具、材质、配色 | 地点名 |
| 变体 tag 已经带的状态（`_daixue` 已经带血，就不写"满脸是血"） | 图上没有、这场才发生的变化（"袖口被扯破""外套已脱"），只写变的那部分 |
| "与参考图一致""100% 匹配参考"这类话 | 位置、走位、哪只手拿什么、视线方向 |
- **没挂图的**（群演、一次性道具、`unbuilt[]` 里的）才用文字定：年龄性别 + 身份 + 一个看得见的锚点，一句话，不展开（"一名四十岁上下、深色夹克的男乘客"）。
- **唯一例外（EV 11-07）**：两个长得像的人同框、怕模型认错时，允许加**一句**看得见的区分特征（"左边戴眼镜的那位是周明"），其余仍不写外观。

### 1.5 Shot 分段
- 每个镜头写成 `Shot01：` `Shot02：`……，一镜一行。时间写法按模型（SD2.0 不写秒；SD2.5 写整数秒；Wan 可写整数秒；见各节）。
- 时间段写成 `0–4 秒` 或 `0-4 秒`（后面带“秒”）。不带“秒”的 `0-4` 会被 build.mjs 当成场号组号拦下。
- 每个 Shot 内的顺序：**景别 + 机位/运镜（只写一种）→ 谁在做什么 → 台词 → 本镜音效**。
- 每条提示词是**独立上下文**：不写"接上一组""同上""再次""延续""比刚才更……"，一律写绝对状态（AIMV 硬约束 1；CineDance 语境隔离）。
- 不写场号、组号、镜号、资产 tag（`@char_…` `@loc_…`）、剧本标题、上一场摘要。
- 人名用全名，不用"两人""他们"这种集合指代；两人同框写清谁在左、谁在右，全组不换边。
- 开口或有动作的群演单独点出（"后排一名中年男乘客"），背景群演可以只写数量（"几名乘客的剪影"）。
- 多人做同一个动作加节奏词：依次、先后、紧随其后（防齐步走）。
- 刚离画的角色，必要时下一组第一个 Shot 写一句"从画面左侧出画、手里还拿着票袋"（Shotlist 离场提示）。

### 1.6 台词与声音四要素
- **台词的字逐字照 `groups[].lines[].text` 抄**，不改、不加、不删；`note` 里注明是错字的（如"误→诶"）按 note 写。
- **但台词要导（EV 11-08，细则见 07 第二节之二）**：可以改标点（加"……""——"）、在一句中间断开、两段之间插动作和停顿；动作写在台词符号外面。拆开的几段按顺序连起来必须和 `lines[].text` 一字不差（build.mjs 查）。
- **反应镜头里台词垫在听者脸上**时写明 `甲的声音在画外继续，乙嘴唇紧闭，没有说话`（细则见 03 第四节之二）。
- **台词符号按各模型官方（EV 11-07 已裁定）**：

  | 模型 | 符号 | 句式 | 依据 |
  |---|---|---|---|
  | SD2.0 | `{}`；音效写 `<>`、音乐写 `（）`（11-07 按手册统一） | `童嘉许说：{先生，你……}`；`<刹车尖响>` | 火山方舟 2.0 提示词指南"特殊字符规范"表：台词 `{}`、音效 `<>`、音乐 `（）`、字幕 `【】` |
  | SD2.5 | `“”` | `童嘉许台词（压低声音）：“……”` 或 `童嘉许说：“……”` | 火山方舟 2.5 指南 FAQ"字幕约束不生效"示例 |
  | H3 / Wan3.0 / Omni | `“”` | `童嘉许说：“……”` | h3-prompt-guide 示例；万相、Omni 示例 |

- 句式：`说话人（语气，可选）说：` + 台词。语气放在冒号**前**。
- **SD2.5 硬规矩**：台词**后面不追加**语气、表情、动作描述，也不复述台词里的词——火山 2.5 指南原文："避免在台词后复述词语并追加语气、表情、动作等描述，此类描述容易诱发字幕生成"；要差异化就拆成 `角色台词（情绪）：“内容”`。后续动作另起一句、写在下一个时间段里。其它模型不受此限，但同样建议语气放冒号前。
- 画外音写明"画外音"；广播、电话等写明声源。
- 多人同框时写清谁开口，必要时补"其他人闭口"。
- 没有台词的组明写 `无对白`（Wan 不写会自己加；SD2.5 支持单独否定对白）。
- **声音四要素**：本组有台词的角色，若资产盘点 `bios[]` 里有档案，把 `voice` 四个字段按 `register；tempo；accent；manner` 顺序原样贴成一行：
  `童嘉许的声音：中偏低的女声，胸腔为主……；中速，句子短……；本地城市口音……；对外客气利落……。`
  - 原样贴、每组都贴、不按场次改；不开口的角色不贴。
  - 找档案：组里的服装 tag（`@char_tongjiaxu_shoupiao`）→ 盘点 `outfits[].char`（`@char_tongjiaxu`）→ `bios[].char`。
  - `arc[]` 里另有一套 `voice` 时，贴哪一版由导演定，不自己挑；在 `unsure` 里提一句。
  - 群演没有档案：写一句"年龄性别 + 音色 + 口音"即可（"嗓音粗、带本地口音"）。
- 台词长度要装得进镜头时长（H3 官方：口型问题多半出在这里）。粗估中文 4–5 字/秒（推断，未实测），超了就拆组或把台词跨到下一个 Shot。

### 1.7 细微生理反应：以各模型官方手册为准（EV 11-07 已裁定）

AIMV"不写细微生理反应"是旧模型时代的结论，**作废**。按模型写：

| 模型 | 写法 | 依据 |
|---|---|---|
| SD2.0 | **情绪具象外化**：可写"肩膀微微颤抖、眼眶泛红、手指攥紧衣角"这类身体细节，替代"很悲伤" | 火山方舟 2.0 指南"情绪具象外化表达"对照表 |
| SD2.5 | 表情用**描述性语句**（"脸上带着满足的笑容"），不用强烈情绪词（"狂热""极度震惊"）；近景人脸且情绪强时加 `人物为正常人眼，眼睛不发光。`；台词后不追加表情动作（见 1.6） | 火山方舟 2.5 指南"动作/表情描述""情绪过度响应（眼睛发光）""字幕约束不生效" |
| H3 | **微表情只放近景 / 特写**；中景、全景不写微表情（写肢体动作） | h3-seedance-prompt `cinematography-guide.md` 景别承载表、"表情与微动作" |
| Wan3.0 / Omni | 手册没专门说，按通用写法：看得见的动作和表情，不写内心 | — |

### 1.8 禁用写法
- 抽象情绪词（"很悲伤""极度震惊""狂热"）、成语式表情（"津津有味"）→ 改成看得见的动作或平常说法。
- 比喻句、内心戏、叙事意图（"全片情感高潮""心头一松"）。
- "眼中映出……""瞳孔里倒映……"（会在眼球上画东西）。
- 一个 Shot 里同时要推、拉、摇、移。
- 画面里的小字、精细图案、徽记、五角星。
- 同一事件叠多种特效运镜（慢镜头 + 手持 + 变焦）。
- 未经要求的背景音乐（默认写"不要背景音乐"）。

### 1.9 收尾约束（短，只写必要几句——EV 11-07 已裁定）
- 默认：`不要字幕，不要背景音乐。`
- 两人及以上同框：加 `同一画面中每个角色只出现一次。`（2.0 官方防双胞胎句的精简版）
- 不写大段通用负面清单（CineDance；2.5 官方只建议反向控制字幕和声音）。

## 二、Seedance 2.0（主要角色文戏）

### 模板
```
[stylePrefix]@image1 是A，@image2 是B，@image3 是[地点名]。
A的声音：[register]；[tempo]；[accent]；[manner]。
B的声音：……。
Shot01：[景别]，[一种运镜]。[A 的动作，细到手/头/肩，写清幅度速度与过渡；情绪写成身体细节]，A说：{……}
Shot02：……
Shot03：……
<环境音/音效>。同一画面中每个角色只出现一次。不要字幕，不要背景音乐。
```

### 写法要点
- **音效写在 `<>` 里，音乐写在 `（）` 里**（火山 2.0 手册“特殊字符规范”，11-07 统一按手册）。
- **台词用 `{}`**（火山 2.0 手册"特殊字符规范"：台词 `{}`，手册里的场景示例也是 `笑着问 {考得怎么样呀，过了吗}`）。
- **镜头只写 `Shot01/02/03`，不写秒数**（官方：精确时间支持不稳定，强行限时会异常）。一组 15 秒放 2–4 个镜头。
- **动作细到肢体**：手、腿、头、肩背，加幅度/速度/力度（缓慢抬手、微微低头）。
- **写清过渡（EV 11-07）**：前后动作怎么接（"借着转身顺势抬手""停一拍再开口""目光先停在手背上，再慢慢抬到她脸上"）。
- 优先低缓、连贯的小动作；避开狂奔、大跳、剧烈翻滚。
- **情绪具象外化**（EV 11-07 按官方）：悲伤 → 低头、肩膀微微颤抖、眼眶泛红、手指攥紧衣角；紧张 → 手指敲桌面、眼神闪躲。身体细节可以写，不写"很悲伤"。
- 一个镜头只指定一种运镜。
- 参考人物 ≤4 个；超过就拆组。
- 文戏要一镜到底时用"延长"续写；武戏、蒙太奇分段生成再剪（官方"延长 vs 分段拼接"）。
- 长度：API 建议中文 ≤500 字；前缀 + 声音原样贴超了也照贴，不删（EV 11-07）。

## 三、Seedance 2.5（需要 LAYOUT 的复杂镜头）

### 模板
```
[stylePrefix]@image1 是[地点名]……@video1 是灰模预演：只参考其中[对象]的位置、路线、先后顺序和摄影机运动；不参考它的灰色外观、方块形状和辅助线，也不参考小人的动作。@video1 里的[几何体]是[什么]。
[开口角色的声音四要素，没人开口不写]
[一句话概述：主体 + 地点 + 事件 + 题材 + 特殊运镜]
画面里有：[把要出现的人、车、道具、灯、背景人群逐一列出]；[不要出现的写明：路上没有行人]。
Shot01（0–4 秒）：[概括动作]
Shot02（4–7 秒）：……[有台词时：A台词（语气）：“……”，台词后不再追加任何描述]
Shot03（7–10 秒）：……
[音效]。不要字幕，不要背景音乐。
```

### 写法要点（和 2.0 反着来，别写反）
- **动作概括写（EV 11-07）**（"三辆车依次超车并线"），只挑 1–2 个有记忆点的动作写细；同一个动作不重复写。
- **照字面执行：写了什么才有什么**（出处：网上实测说法，Q57，社区证据、样本少；不是官方手册原文——之前误标成官方，已更正）。画面元素列全——背景有没有人、有没有别的车、灯亮没亮，都要写；只列"有什么、在哪"，挂了图的东西仍不写长相。
- **情绪、表情用描述性语句和平常说法**，不用强烈情绪词（官方：会引起"眼睛发光"）。有近景人脸且情绪强时，加一句 `人物为正常人眼，眼睛不发光。`
- **时间戳只用整数秒**（EV 11-07 已裁定）、首尾相接（0–4、4–7、7–10），不跳段；单段内容别塞太满（会过度剪切或漏戏），也别用时间戳控制频率（"一秒摇头三次"）。时间段后面带“秒”。
- 参考素材已经够准时**只指代、不复述**：灰模里已有的路线不再逐步描述，只写灰模给不了的（车是什么、光、声音）。
- `@video` 灰模：写明参考哪几样（位置、路线、顺序、机位与运动），写明不参考哪几样（灰色外观、色块、辅助线、小人的动作）；叠了参考图要写对应关系；灰模里没有的东西才用文字补，且文字要和灰模动线一致。多机位的预演剪成一条视频挂一个 `@video1`，分段对上 Shot01–03（EV 11-07），输出画幅跟灰模一致。
- 复杂要求别全压在一次生成里：官方建议拆成几个简单任务分次生成再剪。
- 台词写成 `童嘉许台词（压低声音）：“……”`，**台词后面不再追加语气、表情、动作**（官方：容易诱发字幕）。
- 避开"水、波浪、回音"类描述（官方：易出水波纹噪声）。
- 派单提醒（04 管）：2.5 与 2.0 风格差别大，同一场戏不混用。

## 四、H3（群演有台词、带切镜）

### 模板
```
[stylePrefix]@image1 是[主角名]，@image2 是[地点名]。
[一句话概述：主体 + 地点 + 事件 + 题材 + 切镜方式]
Shot01：[景别]，[shot 内运镜]。[内容/动作]。[谁]说：“……”（画外音写明画外音）
Shot02：……（一句台词跨镜头写"接着上个shot继续说"）
Shot03：切到[哪个角色]，[景别]……
音效：……。非叙事性音乐：N/A，不要额外添加背景音乐。不要字幕。
```

### 写法要点
- 三段公式：参考素材说明（一句话，绑一次）+ 核心创意一句 + 逐 Shot 画面过程。
- 每个 Shot 写全：景别 + 内容 + shot 内运镜 + 台词 + 音效。H3 对切镜点遵从较强。
- 台词用 `“”`。
- **微表情只放近景 / 特写**（EV 11-07，按 cinematography-guide）：近景、特写写表情或眼神（5–8 字，"眉头一皱，抬眼往车头看"）；中景、全景不写微表情，只写肢体动作。
- 切镜时写清"切到什么景别、拍的是谁"，帮它跨镜头保持一致。
- 台词长度对齐 Shot 长度；一句话跨两个 Shot 用"接着上个shot继续说"（J/L-cut）。
- 群演没挂图：一句话定人（年龄性别 + 身份 + 一个锚点）+ 一句话定声。
- 主角只有动作、不开口：不贴主角的声音四要素。
- 不要配乐写成 `非叙事性音乐：N/A`；要配乐写乐器 + 速度 + 节奏，不写抽象情绪。
- 少比喻，多写看得见的画面；素材多、镜头多时整条写到 200–400 字，太短会被自由发挥。
- 环绕运镜写 `truck left + pan right`，不直接写"环绕"。
- 平台参数：走 H3 Max API 时把提示词扩写关掉（`prompt_expansion_mode = disabled`，推断）。
- **注意（只有一对样本，不是规则）**：EV 听感——同一句提示词，2.5 演得比 H3 更 Happy，H3 偏平。H3 组的情绪可能要写得比 2.5 明确半档；先在本组 `unsure` 里记一笔，等更多样本再定。

## 五、Wan3.0（参考生视频 · 有物理过程的物件特写）

### 模板
```
[stylePrefix]@image1 是[地点名]，@image2 是[道具名]。
生成单镜头，一镜到底。[一句话：什么东西、在哪、发生了什么物理过程]
Shot01（0–N 秒，一镜到底）：0–2 秒[起始状态]；2–5 秒[过程：力从哪来、往哪去]；5–N 秒[最终状态：停在哪、什么姿态]。
无台词。音效：[材质碰撞声]；无bgm，只生成环境音和动作音。
不要切镜，画面里只有物件和必要的手部，不要人物全身或脸入画，不要字幕。
```

### 写法要点
- **首行写"生成单镜头，一镜到底"**，负向再写"不要切镜"——Wan 会擅自切镜（官方写法 + 第三方评测）。
- 真要多镜头时：`Shot01（0–3 秒）` 序号 + 时间戳，每段 2–5 秒，首尾相接不重叠。
- 台词（如有）用 `“”`；表情按通用写法（手册没专门说）。
- 固定机位写死：`固定镜头，摄影机静止，机位不变`。焦段、景深、高速摄影（"1000fps 慢动作"）可以直接写。
- **物理过程写三段**：起始状态 → 受力与轨迹 → 最终状态；用"角度、方向、停在哪"收尾，不写结论（"散落一地"不如"一枚硬币绕圈转几下后倒下停住"）。写明材质（硬币、纸币、玻璃），声音会跟着材质来。
- 不要台词就写 `无台词`，不写模型会自己加。BGM 三选一：不写 / 指定 / `无bgm，只生成环境音和动作音`。
- 负向清单只写会出事的，不凑数（官方常用：不要频繁切镜、不要多人同屏）。
- 参考图挂了道具就不写道具长相；没建档的道具要先出一张道具图再派 Wan（分档表：参考生视频 + 道具参考图）。
- 平台参数：`prompt_extend` 关掉（默认开，会重排写好的分镜）；输出 30fps，剪辑时和其他模型的 24fps 统一。
- 审核偏严（第三方）：血腥、暴力字眼可能直接被拦，物件特写里能不写"血"就不写。

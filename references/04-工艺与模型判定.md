# 04 工艺与模型判定

> 来源：EV 11-05 至 11-07 多轮拍板；15 期 Q45/Q47/Q57/Q60/Q61。这张分档表是这个 Skill 的卖点：外行一眼看懂“不同工艺整合在一张表里”。

## 一、分档表（v1）

| 镜头组是什么 | 工艺 | 模型 |
|---|---|---|
| 简单空镜、静态物件特写（不切镜） | 首帧生视频，首帧 = Gemini 单张生图 | **Omni** |
| 要切镜的空镜，没有群演或群演不说话 | 首帧生视频，**默认 Omni 一次出多镜**（时间码分镜，≤10 秒）；备选：Gemini 宫格逐镜 | **Omni** |
| 超过 10 秒的长空镜 | 首帧生视频（2–30 秒） | **Wan3.0** |
| 带切镜、**群演有台词**的镜头（主角不说话或只有动作） | 参考生视频 | **H3** |
| 主要角色的文戏（对白） | 参考生视频 | **SD2.0** |
| 复杂镜头 = **需要 LAYOUT** 的：多个对象的位置、路线、先后顺序、机位运动（暂定） | 参考生视频 + LAYOUT 视频（附 Blender MCP 提示词，见 08） | **SD2.5** |
| 有物理过程的物件特写（落地、碎裂、抛壳）（不需要 LAYOUT） | 参考生视频 + 道具参考图 | **Wan3.0** |
| 人身上的细节动作（脚背勾窗台、撑地趴下） | **不上实拍自演**；改设计 / 拆镜（拆成特写、切掉过程） | 按拆完后的镜头重新判 |

## 二、判定顺序（从上往下，命中即停）

1. 有没有**主要角色说话**（**内心独白 OS 也算说话**，用的是本人声音——EV 11-07）？有 → **SD2.0**；其中动作关系复杂、要 LAYOUT 的 → **SD2.5**。（主要角色的声音只交给 Seedance，保证全片一致。）
1.5 **主要角色出镜但不说话**（只露手、不露脸的特写不算出镜）：要 LAYOUT 的 → **SD2.5**；否则 → **H3**（参考生视频，挂角色图锁脸；不开口就没有声音穿帮的风险——EV 11-07）。首帧档锁不住主角的脸，所以主角出镜不进首帧档。
2. 有没有**多对象的位置 / 路线 / 时序**要锁死？有 → **SD2.5 + LAYOUT**。人群整体的简单动线（四散、涌向某处）不算——交给模型自由发挥更自然（EV 11-07，见 08 反例表）。
3. 有没有**群演说话**？有 → **H3**。**只限只出场一次的群演**；反复出场、有台词的小配角（即使没建档，例：一直跟着男主的手下）跟主角走 **SD2.0**，并在该场 `unsure` 里提醒副导演补建档（EV 11-07）。
4. 是不是**有物理过程的物件特写**？是 → **Wan3.0**（参考生视频）。
5. 剩下的（没有主要角色的空镜、静态特写、不说话的群演）→ 首帧生视频：≤10 秒 → **Omni**；>10 秒 → **Wan3.0**。

> **混合情况**（EV 11-07 确认）：一组里主角对白为主、夹一句群演台词（例：手下汇报一句），按第 1 条走 SD2.0——主角声音优先。
> **主角对白 + 多车调度同时出现**：拆组。调度那几秒单独一组走 2.5 + LAYOUT，对白另一组走 2.0。

## 三、为什么这么分（写派活理由时用得上）

- **声音一致性**：换模型就换了声音（EV 在 PR 对比页里听出：像同一个人，但 2.5 偏 Happy、H3 偏平）。PR 当时是文字锁声音，没传参考音频。所以主要角色的对白统一给一个模型。
- **群演给 H3**：群演只出场一次，没有跨镜头的长相和声音一致性要求，正好避开混用风险。
- **首帧档只放不说话的镜头**：首帧生视频和参考生视频在 Seedance / H3 / Wan 的 API 里互斥（官方原文），首帧模式挂不了参考音频，锁不住声音。
- **实拍自演不进 v1**：CHB 挂自拍视频的生成 3,244 条，确认进成片的只有 84 场 2 条，而且只借运镜不借动作；105B 自拍和灰模都没在成片里定位到（Q45）。LAYOUT 只管“形”，人身细节靠改设计。
- **物理特写给 Wan3.0**：第三方评测说它的物理效果（碎玻璃、台球）强于 SD2.0（Q61，证据是第三方）。

## 四、派活理由怎么写（`reason` 字段）

一句话：**是什么镜头 → 命中第几条 → 模型**。例：
- “两位主角的对白，六句 → SD2.0”
- “开口的是黑衣人和乘客，都是群演；主角只有动作 → H3”
- “三辆车超车、并线、横停：多对象的路线和先后顺序 → SD2.5 + LAYOUT”

## 五、未建档的人和物

资产盘点只收跨场景的道具，一次性道具和群演不建档。分镜里：
- 写进该组 `unbuilt`，如“黑色轿车 ×3（一次性道具，未建档）”；
- 提示词里用泛称写（“三辆黑色轿车”“一名中年男乘客”），不编造外观细节；
- 主要角色缺资产（盘点里查不到）→ 不要自己编 tag，记进该场 `unsure`，请导演让副导演补建。
- **派给 Wan3.0 的物件特写，道具没建档**（剑、箭这类一次性道具）：物理特写靠道具参考图，记进该场 `unsure`，请副导演把这件道具补建档（一次性道具为了出图也可以建）。
